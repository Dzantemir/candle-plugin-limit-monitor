# Концевики — плагин мониторинга концевиков для Candle в реальном времени

[English version](README.md)

Компактная панель Candle, которая **в реальном времени** показывает, какие
входы GRBL активны, и **предупреждает** в момент нажатия концевика: цветные
индикаторы по осям, заметная красная строка предупреждения и звуковой сигнал.
При нажатом концевике панель также может предложить кнопки съезда `$T` в один
клик — для прошивки [ALOE FIXED7](#кнопки-съезда-t-прошивка-aloe-fixed7).

```
[X][Y][Z] [P][D]      <- индикаторы входов
КОНЦЕВИК: X !         <- строка предупреждения
$T: [X-][X+]          <- кнопки съезда (только нажатые оси)
```

## Что показывает

| Индикатор | Значение |
|---|---|
| **X / Y / Z** | концевики осей: зелёный = отпущен, **красный = нажат**, серый = нет данных |
| **P** | вход щупа активен (оранжевый, информационно — без тревоги) |
| **D** | вход дверцы активен (оранжевый, информационно) |
| строка статуса | `ОК` / `КОНЦЕВИК: X Y !` / `нет статуса...` / `нет подключения` |

Дополнительно:

* **звуковой сигнал** по фронту «отпущен → нажат» любого концевика (один
  сигнал на событие, взводится заново после отпускания; отключается в
  настройках);
* входы `H`/`R`/`S` (hold / reset / cycle start) показываются текстом `Pn: ...`;
* **без устаревшей лжи**: если статус-репорты не приходят больше 2.5 с или
  порт закрыт — все индикаторы становятся серыми («нет данных»), а не
  показывают последнее известное состояние.

## Кнопки съезда $T (прошивка ALOE FIXED7)

Пока концевик нажат, появляется строка `$T:` с кнопками **только для нажатых
осей** (`X-`/`X+`, ...). Клик отправляет `$TX-`, `$TX+`, `$TY-`, ... — команду
автосъезда форка ALOE FIXED7: ось сама медленно съезжает с концевика на
скорости хоминга `$24` (до 10 мм), затем отъезжает на `$27` — всё движение
выполняется внутри прошивки, без джоггинга.

* Кнопки активны только в состоянии **Idle/Alarm** и когда не идёт отправка
  g-code программы (та же логика готовности, что у официальных плагинов).
* На **стоковом GRBL** команда безвредна: контроллер ответит `error:3`,
  движения не будет.
* Всю строку можно скрыть на странице настроек плагина.

## Как это работает

GRBL 1.1 включает поле `Pn:` в статус-репорт
(`<Idle|MPos:...|Pn:XYZ|...>`) только когда активен хотя бы один вход;
отсутствие поля `Pn:` означает, что все входы отпущены. Candle и так
непрерывно опрашивает контроллер командой `?`, а плагин получает каждый
сырой репорт через скриптовый сигнал `app.device.statusReceived` и разбирает
поле `Pn:`.

Плагин **не шлёт контроллеру собственных команд** — трафик по порту остаётся
ровно таким, каким был (единственное исключение — `$T...` по клику на кнопку
съезда).

## Установка

1. Скопируйте папку `limit_monitor` в папку `candleplugins/` рядом с
   исполняемым файлом Candle.
2. Перезапустите Candle. Панель «Концевики» появится среди панелей (если
   скрыта — включите в меню **Вид**).

## Требования

* актуальная сборка Candle с поддержкой JS-плагинов — папка `candleplugins`
  и скриптовый сигнал `app.device.statusReceived` (актуальные исходники
  Denvi/Candle);
* **GRBL 1.1+** — формат поля `Pn:` статус-репорта;
* жёсткие лимиты (`$21`) **не обязательны**: `Pn:` сообщает физическое
  состояние входов независимо от настроек `$5`/`$21`/`$10`;
* кнопки `$T` полезны только с прошивкой ALOE FIXED7 (в остальных случаях
  безвредны).

## Настройки

Страница плагина в настройках Candle:

* **Звуковой сигнал при срабатывании концевика** (по умолчанию: вкл.);
* **Показывать кнопки съезда $T (прошивка ALOE FIXED7)** (по умолчанию: вкл.).

Хранятся в `limit_monitor/settings.ini`.

## Разработка

Плагин — чистый QtScript + формы Qt Designer, без компиляции. Логика
(разбор статуса, конечный автомат индикации, детектор фронта для сигнала,
гейты готовности `$T`, круговорот настроек) покрыта офлайн-тестами с
заглушками API Candle, включая его поиск виджетов только среди прямых
детей:

```
node tests/harness.js
```

Русский перевод интерфейса: `translation_ru.ts` (исходник) /
`translation_ru.qm` (скомпилирован, Candle подхватывает его автоматически при
русском языке интерфейса). Пересборка:
`lrelease translation_ru.ts -qm translation_ru.qm`.
