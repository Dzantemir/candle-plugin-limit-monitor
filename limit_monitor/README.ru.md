# Концевики (Limit switches) — плагин для Candle

Компактная панель, которая **в реальном времени** показывает, какие входы GRBL
активны, и **предупреждает**, когда нажат концевик.

```
[X][Y][Z] [P][D]  КОНЦЕВИК: X !
$T: [X−][X+]
```

* **X / Y / Z** — концевики осей: зелёный = отпущен, **красный = нажат**, серый = нет данных.
* **P** — щуп (Probe): оранжевый = активен (информационно, без тревоги).
* **D** — вход защитной двери: по умолчанию серый — **«не отслеживается»**.
  GRBL сообщает `Pn:D` только пока считает дверь ОТКРЫТОЙ, и только если
  прошивка собрана с `ENABLE_SAFETY_DOOR_INPUT_PIN` (в стоковом GRBL и в
  ALOE FIXED7+ он выключен), поэтому на станке без датчика двери зелёный
  индикатор был бы ложным «всё ок». Если датчик реально установлен —
  включите отслеживание в настройках плагина: тогда оранжевый = открыта,
  зелёный = закрыта.
* Текст справа: `ОК` / `КОНЦЕВИК: X Y !` / `нет статуса...` / `нет подключения`.
* Если статус-репорты перестали приходить (>2.5 с) — индикаторы честно
  становятся серыми «нет данных», а не показывают устаревшее состояние.

## Кнопки съезда $T (прошивка ALOE FIXED7+)

Когда концевик нажат, появляется блок `$T:` с кнопками только для нажатых
осей, парами по осям (`X−`/`X+`, `Y−`/`Y+`, `Z−`/`Z+` на отдельных строках) —
панель не вылезает за узкую колонку дока, даже если сработали все оси сразу. Кнопка отправляет `$TX-`, `$TX+`, `$TY-`… — команду
автосъезда прошивки **ALOE FIXED7+**: ось сама медленно (скорость `$24`)
съезжает с концевика (в пределах бюджета `$29`, по умолчанию 10 мм), делает отъезд `$27` — целиком внутри прошивки.

* Кнопки активны только в состоянии **Idle/Alarm** и когда не идёт отправка программы.
* Из **Alarm** кнопка сначала автоматически шлёт мягкий сброс (Ctrl-X) — это
  нужно, чтобы выйти из стоковой критической блокировки `ALARM:1`, которая
  выбрасывает строчные команды до realtime-сброса. `$T` уходит по **первому
  статус-репорту после того, как Candle увидел баннер перезагрузки** (то есть
  контроллер гарантированно снова жив); сторожевой таймер отменяет цепочку,
  если контроллер не вернулся, а если концевик за это время отпустили —
  цепочка тоже отменяется.
* На **стоковом GRBL** команда безвредна: контроллер ответит `error:2`, движения не будет.
* Кнопки можно скрыть в настройках плагина.

## Как это работает

GRBL 1.1 включает поле `Pn:` в статус-репорт `<Idle|MPos:...|Pn:XYZ>` только
когда хотя бы один вход активен; отсутствие поля = всё отпущено. Candle
непрерывно опрашивает контроллер командой `?`, а плагин получает каждый сырой
репорт через сигнал `app.device.statusReceived` и разбирает `Pn:`.
Никаких дополнительных команд контроллеру плагин не шлёт (кроме `$T` по кнопке
съезда и мягкого сброса Ctrl-X первым шагом цепочки из Alarm).

Буквы `Pn:`: `X Y Z` — концевики, `P` — щуп, `D` — дверца, `H` — Hold,
`R` — Reset, `S` — Start. `H/R/S` показываются текстом `Pn: ...` справа.

## Установка

1. Скопируйте папку `limit_monitor` в папку `candleplugins/` рядом с
   исполняемым файлом Candle.
2. Перезапустите Candle. Панель «Концевики» появится среди панелей
   (меню Вид/Панели, если скрыта).

Требуется сборка Candle с поддержкой JS-плагинов (папка `candleplugins`,
актуальные исходники Denvi/Candle) и GRBL 1.1+ с включённым полем `Pn:`
(`REPORT_FIELD_PIN_STATE` в config.h — в стоковом GRBL включено по
умолчанию; если его выключить при сборке, плагин не отличит «всё отпущено»
от «состояние не передаётся» и будет показывать концевики отпущенными).

### Проверка прошивки

При каждом подключении плагин один раз шлёт `$I` и ищет в ответе метку
сборки ALOE. На чужой прошивке кнопки `$T` и цепочка Ctrl-X в Alarm
полностью отключаются — остаётся только мониторинг пинов. Пока идёт съезд
`$T`, GRBL (как и при стоковом хоуминге) не отвечает на опрос `?`, поэтому
панель показывает явное сообщение «выполняется съезд $T...» вместо «нет
статуса». Проверено с ALOE FIXED9/FIXED10.

## Настройки

Страница плагина в настройках Candle:

* **Показывать кнопки съезда $T** (вкл. по умолчанию).
* **Отслеживать вход защитной двери (Pn:D)** (выкл. по умолчанию — см.
  примечание про индикатор **D** выше).

Хранятся в каталоге данных Candle в файле `plugin_limit_monitor.ini`
(`QStandardPaths::AppDataLocation` — доступен на запись даже при установке
Candle в `C:\Program Files`). Старый `limit_monitor/settings.ini` прежних
версий читается один раз как запасной вариант — настройки мигрируют сами.
